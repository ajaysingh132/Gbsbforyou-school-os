# GBSBFORYOU School/OS v1.0

Multi-institution institutional operating system foundation.

- GBSBFORYOU is the core software platform.
- Each institution maintains its own identity, branding and operational data.
- Institution data is logically isolated by tenant/institution scope.
- Platform updates are separate from institution-data updates.
- AI operates only within authorized institution scope.
- Designed for offline-first expansion, local server, sync, cloud memory, RBAC and audit.

## Run
npm install
npm run dev
